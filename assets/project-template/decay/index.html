必需列：date,page,clicks,impressions；可选：ctr,position。每行代表一天、一个页面。日期用 YYYY-MM-DD。最多 20 MB / 20 万行。

GSC 网页里的“页面”汇总和“日期”汇总是两张不同的表，不能拼出这张热力图。使用本开源 Skill 的 fetch_content_decay.py，从官方 API 按天取数；只需 GSC 只读访问，不需要 GA4。也可导入已有的同口径 CSV。
